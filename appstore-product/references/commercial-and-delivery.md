# 商用素材与交付

## 来源分类

对每个最终可见元素标注以下来源之一：

- 用户/团队自有：App UI、图标、品牌资产、自产照片与文案。
- 开源许可：字体、图标或纹理；保存原始下载地址、版本、许可证全文和必要署名。
- 商业授权：保存授权主体、使用范围、订单或许可证凭证；不要把凭证公开打包给无关人员。
- 生成式素材：记录生成工具、日期、完整提示词、后续编辑和是否含参考图。
- 代码生成：记录生成文件和使用的第三方依赖/许可证。

缺少来源的信息不能写成“完全可商用”。应明确列为待用户确认，并尽量替换成可追溯素材。

## 风险边界

- 不擅自抓取网页图片、社交媒体内容、电影海报、名人肖像、品牌 Logo 或不明字体。
- 开源不等于无条件商用；检查字体嵌入、再分发、修改和署名条款。
- AI 生成内容的可保护性和排他性因地区与事实不同；只描述生成和许可事实，不承诺独占版权。
- App UI 中由用户上传的演示内容，也必须是自有、授权或为本次原创生成。
- 不使用 Apple 奖项、编辑推荐等标识，除非确有资格且符合 Apple 使用规则。

## 素材来源与许可说明最少字段

| 字段 | 内容 |
|---|---|
| 资产名称/文件 | 可定位到源文件 |
| 类型 | UI、照片、插画、字体、图标、文案等 |
| 来源 | 自有、URL、供应商或生成工具 |
| 作者/权利人 | 已知时填写 |
| 许可 | 自有、OFL、商业授权等 |
| 使用范围 | App Store 素材、源文件再分发等 |
| 备注 | 修改、裁切、提示词、归属要求 |

## 交付包

“可上传包”只包含最终图片和必要的上传说明；不要混入源字体、红框检查图、缩略图、脚本、`.DS_Store` 或嵌套压缩包。

“可编辑源文件与许可包”可包含：

- 可编辑布局源文件与导出脚本。
- 原始 UI 截图、原图、字体及许可证。
- 生成式素材提示词和生成记录。
- manifest/checks、安全区坐标和哈希。
- 素材来源与许可说明。

两个包都应测试可解压。上传说明列出版位到文件的精确映射、尺寸、语言、适用设备、官方规格核对日期和验证结果。

## 最终措辞

可以说“尺寸和文件格式已按核对日期的 Apple 官方规格验证”“素材来源与许可已随包记录”。不要说“保证审核通过”“绝对没有版权风险”“已经上线”，除非分别有 Apple 审核结果、法律结论或真实发布证据。
